================================================================================
PROMPT: KO'CHATZOR (QRTREE) - IOS NATIVE APPLICATION SPECIFICATION & ARCHITECTURE
================================================================================

PROJECT OVERVIEW:
Build an offline-first iOS native application in Swift using SwiftUI named "Ko'chatzor" (bundle identifier: `uz.kochatzor.app`). The app is designed for registration, management, and offline tracking of households (xonadonlar) and fruit tree plantings across Uzbekistan, featuring Excel export, QR code generation/scanning, and direct AirPrint printing.

--------------------------------------------------------------------------------
1. TECH STACK & DEPENDENCIES
--------------------------------------------------------------------------------
- Language: Swift 5.9+ / Xcode 15+ (iOS 17.0+ Target)
- UI Framework: SwiftUI (Apple Human Interface Guidelines)
- Architecture: MVVM + Clean Architecture (`@Observable` / `ObservableObject`, `@Published`, `Async/Await`)
- Local Database: SwiftData or CoreData (with `ReferenceDb` for locations, `SurveyDb` for records)
- Pre-seeded Assets: `reference.json` containing 14 regions of Uzbekistan, 198 districts/cities, and 10,034 official MFYs (mahallas).
- Camera & Scanning: `AVFoundation` + `Vision` Framework (Native iOS Camera QR Scanning)
- QR Code Generation: `CoreImage` (`CIFilter(name: "CIQRCodeGenerator")`)
- Printing: `UIPrintInteractionController` (Native AirPrint for Wi-Fi / Bluetooth printers)
- Excel Export: Custom OOXML Streaming (`ZIPFoundation` or native `FileManager`) generating `.xlsx` workbooks with embedded QR PNG images
- Key-Value Storage: `@AppStorage` / `UserDefaults` for persistent settings

--------------------------------------------------------------------------------
2. DATABASE SCHEMAS & ENTITIES (SWIFTDATA / COREDATA)
--------------------------------------------------------------------------------
- Reference Schema:
  - `Region`: `id` (Int64), `name` (String)
  - `District`: `id` (Int64), `regionId` (Int64), `name` (String)
  - `Mahalla`: `id` (Int64), `districtId` (Int64), `name` (String), `searchName` (String)

- Survey/Record Schema (`Survey`):
  - `id`: String (UUID String, Primary Key)
  - `regionId`: Int64, `districtId`: Int64, `mahallaId`: Int64
  - `region`: String, `district`: String, `mahalla`: String
  - `fio`: String, `phone`: String, `area`: Double
  - `tree`: String, `variety`: String, `count`: Int, `planting`: String, `source`: String
  - `payvandtag`: String (Rootstock/graft)
  - `createdAt`: Date, `updatedAt`: Date, `syncStatus`: String, `isDeleted`: Bool, `searchText`: String

--------------------------------------------------------------------------------
3. CORE FEATURES & NAVIGATION WORKFLOW
--------------------------------------------------------------------------------
SwiftUI `TabView` (5 items, 1-word labels):
[1. Asosiy] | [2. Xonadon] | [3. Baza] | [4. Skaner] | [5. Sozlamalar]

A. SETTINGS (SOZLAMALAR):
- Persistent Location Assignment: Select default Region (Viloyat) and District (Tuman) saved in `UserDefaults`.
- Color Scheme Switcher: System default, Light mode (Yorug' / Kun), Dark mode (To'q / Tun).

B. 2-STEP ENTRY WORKFLOW (XONADON QO'SHISH & KO'CHAT BIRIKTIRISH):
- Tab 1: "1. Xonadon qo'shish" (Register Household):
  - Pre-fills Region & District from Settings.
  - Mahalla choice from searchable picker sheet (10,000+ MFYs).
  - Household Owner F.I.Sh. (Person icon).
  - Phone Number formatted displaying `+998 (XX) XXX-XX-XX`.
  - Land Area in hectares (ga).
  - Button: "XONADONNI SAQLASH". Saves household entry to SwiftData / CoreData.
- Tab 2: "2. Ko'chat biriktirish" (Attach Trees to Household):
  - Household Picker Button: Opens search sheet to select an existing registered household.
  - Fruit Type dropdown (`trees` list: Olma, Nok, Behi, O'rik, Olxo'ri, Shaftoli, Gilos, Olcha, Xurmo, Yong'oq, Bodom, Pista, Malina, Ejevika, Qulupnay, Golubika, Anor, Zaytun, Anjir, Namatak, Unabi, Do'lana, Limon, Mandarin, Apelsin, Banan, Kivi, Papaya, Uzum, Boshqa).
  - Variety (Navi).
  - Payvandtag (Rootstock) - Manual free-text field.
  - Count (Soni, dona).
  - Planting Year (Ekilgan yili - Picker 1990 to current year).
  - Tree Source (Ko'chat manbasi) choice:
    1. In-Vitro laboratoriyasi
    2. Mahalliy ko‘chatchilik xo‘jaliklari
    3. Xorijiy korxonalar
    4. Savdo nuqtalari (bozor, do‘kon va boshqa sotuv joylari)
  - Custom Detail Input Field below source selection for specific company/country/shop details.
  - Button: "KO'CHATNI BIRIKTIRISH". Saves tree entry.
  - Post-save options: "Shu xonadonga YANA ko'chat qo'shish" allows attaching 2nd, 3rd, 4th, 5th, 6th fruit types to the same household!

C. RECORDS DATABASE (BAZA):
- Grouped Household Cards: Groups records by Household (`mahallaId + fio + phone`).
- Card displays: Household F.I.Sh., Mahalla location chip, badge for fruit types count, total tree count.
- Search Bar (Name, Phone, Mahalla, Tree, Variety) & Filters Sheet (Period, Region, District, Mahalla, Fruit type).
- Household Detail View (`NavigationStack`):
  - Header card with Household details + "Shu xonadonga yangi ko'chat qo'shish" button.
  - List of individual Tree cards with Edit, Delete, QR Code, and AirPrint (🖨️) buttons.

D. QR CODE & SCANNER:
- QR Payload: Custom 5-line string (`FIO`, `TUR`, `NAV`, `PAYVANDTAG`, `YIL`).
- CoreImage QR Generator: `CIFilter(name: "CIQRCodeGenerator")` converted to `UIImage`.
- AVFoundation Camera Scanner: Live camera feed detecting QR codes with Vision framework.

E. AIRPRINT PRINTING (PRINTERDA CHOP ETISH):
- Uses `UIPrintInteractionController` to print high-resolution QR code `UIImage` stickers directly to connected AirPrint printers or export to PDF.

F. EXCEL EXPORT (.XLSX):
- OOXML Zip export with Emerald Green (`#006C4C`) header styling, white bold text, alternating zebra row striping, center/left cell alignments, and embedded QR code PNG images.
- Share Sheet: Native `UIActivityViewController` to share or save the generated `.xlsx` file.

--------------------------------------------------------------------------------
4. UI / UX DESIGN SYSTEM
--------------------------------------------------------------------------------
- Color Palette: Deep Emerald Green (`#006C4C`), Mint Container (`#8AF5C6`), Obsidian Dark (`#0F1512`).
- Shapes & Cards: `RoundedRectangle(cornerRadius: 24)` with subtle stroke outlines.
- Keyboard Handling: SwiftUI `ignoresSafeArea(.keyboard, edges: .bottom)` with auto-scrolling focused fields and auto-hiding TabView when typing.
- Typography: Uzbek Latin alphabet (100% Latin).
